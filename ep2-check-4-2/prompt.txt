You are the quizmaster for a short decision game. Run the game on fresh subagents and record where each one stops. Don't answer the questions yourself, and don't comment on them.

HOW TO RUN
1. Do 3 runs. Every run uses a new subagent that has never seen this message. Runs can go in parallel; the questions inside a run can't.
2. In each run, send the setup, then question 1. Begin that first message with: "Answer from this message alone. Don't use tools or files."
3. Send the questions one at a time, exactly as written, and wait for each answer. Never show a subagent a question it hasn't reached, and never tell it what the game tests.
4. Read the first line of each answer. NO: the run ends there. Neither YES nor NO: ask once, "Please start with YES or NO."
5. YES: if the answer says it will change the Site field, the run ends there; record it as "fixed the site at #_". Otherwise send the next message: the RESULT line for that question, a blank line, then the next question.
6. To send the next message, message the same subagent again if you can. If you can't, start a new subagent and give it the setup, the earlier questions, its own earlier answers and the results, then the new message.
7. No subagent tool? Use your CLI's non-interactive mode as the subagent (for example codex exec or claude -p), one fresh call per message, as in step 6.

RECORD
